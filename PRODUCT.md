# The Quiet Line
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated by the user: Three.js, native WebXR, Vite, plain JavaScript, with an original Blender-authored GLB carriage and painted atlas. Static output deployed through GitHub Actions/Pages. This release adds compact controls and quieter train audio to the carriage introduced in commit `7c04a1f`.

## Users
The owner will explore on a Meta Quest headset later. Desktop preview supports development and exploration without a headset.

## Product Purpose
An immersive, contemplative world inspired by the supplied Dreamy Ocean Sky Storyboard.png: dominant bright, deep blue sky, fewer deliberately placed painted clouds, expansive reflective ocean, and submerged railway.

## Capabilities and Constraints
User explicitly delegated sounds, movement, feel, assets, and design decisions, then authorized a public GitHub repository and GitHub Actions/Pages deployment. Preserve the reference. No account or backend required. Headset performance must be measured on hardware; do not claim verification without it.

The current journey begins at a fixed station on a raised grassy shore. Explicit boarding enters one carriage; left and right window seats, departure, pause/continue and return share the same actions on screen and the in-world VR menu. The train moves while the station and landscape stay fixed. Preserve gaze and real tracked head height, with no forced camera roll or bobbing. Free-water teleportation and the drifting-station concept are retired. The user retained station, boarding and seat actions; free walking is outside the current interaction design. Build and review this first carriage before adding more cars or journey content.

Controls should leave the scene open. Screen exploration keeps only Journey and Menu visible; secondary actions appear on request. The compact VR menu starts closed and opens only through an explicit grip action. Opening menus or adjusting time/sound must preserve the visitor's journey and gaze.

Sound starts only after interaction, defaults to 35% volume and retains mute/volume controls. Quiet filtered rolling noise and distinct, rounded, distance-driven track contacts accompany travel and settle to silence when paused. The user found the first mix too whoosh-like, then heard the bumps but reported an unpleasant low screech. The revised mix raises the paired bumps slightly, removes pitched train tones and softens water and wind inside the carriage. The latest tuning is retained for this release; actual Quest listening remains unverified.

## Brand Commitments
The supplied storyboard is the visual authority, refined by the user's explicit request for fewer clouds and dominant bright, deep blue sky. Later user references refine the clouds' feathery edges and pale-blue/mint washes, the white-and-teal dragon's appearance and more dynamic flight, and a small cottage island beside the railway. These extend the world while preserving the open sky, stable horizon and visitor-controlled camera. Project name and narrative are creative decisions delegated to the builder.

The train references establish a cream/maroon carriage, rounded roof, red bench upholstery, substantial dark window frames and hanging straps. Use original geometry and painted materials without copying reference-image pixels or model parts. The user rejected the current dragon's smooth procedural appearance; historical review approval is not user acceptance, and this carriage milestone does not replace that asset.

## Product Principles
Atmosphere first. Keep horizon stable. Movement is opt-in. Immersion must work without a desktop overlay. Assets ship with the application.
